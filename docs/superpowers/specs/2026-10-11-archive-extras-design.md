# Archive extras design

The user approved adapting the useful GitHub extras after the comparison: interactive dream radar, source-backed educational detail panels and Post/Story cards. Keep the existing Expo/React Native/Supabase application and privacy boundaries. This document makes the previously approved scope concrete; no new provider or paid API is introduced.

- Universal radar: flying, falling, water, teeth, pursuit, maze. Symbolic mode: shadow, depths, threshold, descent, transformation, flight. Match exact normalized tag aliases only; do not search interpretation prose or infer physiology from text. Count distinct ready, non-deleted entries. Percent = matching entries / eligible archive entries; zero remains zero. Show denominator, ties for dominant themes, accessible count/percent buttons; tapping toggles an archive filter. Map covers the full eligible archive, while search/date/tag/theme filters intersect in the list. Symbolic categories are explicitly labelled as groupings, not validated psychology or measurements.
- Dream details: collapsible educational panel, four topics (memory, emotion, plasticity, symbolic reflection), general explanations and personal reflection questions. Show matching recorded themes, never invented EEG/neurotransmitter/consolidation values. Curated bibliography uses verified PubMed titles/IDs/DOIs (23354387, 22119526, 24411729) and distinguishes a review, experimental study and hypothesis/perspective. Bibliography describes general research, not evidence that an individual dream interpretation is correct. No dream text leaves the device for this feature. Links open only after a deliberate tap, with a translated error state.
- Share: select Post (1080×1350) or Story (1080×1920), preview the chosen ratio and export the same dimensions on native and web. Preserve only the current explicit payload: image, title, date, selected tags, source label and watermark; no transcript, interpretations or identity. Use one shared native SVG visual and web SVG serializer layout, with sensible title/tag length limits. Preserve private image embedding and temporary file cleanup.
- All new visible text supports TR/EN; controls expose accessibility labels/selection; layouts work at 320px and wide widths. No new dependencies; use installed react-native-svg. Keep the monochrome theme.
- Copy source files into the new workspace without modifying the old checkout, database or API secrets. Existing dependencies may be reused locally; document this. Preserve the existing .git and comparison report.
- Verify pure theme/count/filter logic, citation catalogue integrity and export geometry/privacy; run existing tests, TypeScript, formatting, and Expo exports for web/iOS/Android. Inspect browser UI and export dimensions where tooling permits. Native device execution remains unverified.

Builder choices: exact spacing, diagram layout, reflection copy and internal file names. Excluded: gamification, sleep sensors, live literature search, AI prompt changes, schema changes and publication.
